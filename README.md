# NASA NEO Asteroid Tracker

A Streamlit dashboard that allows users to explore NASA's Near-Earth Object (NEO) asteroid approach data using interactive filters and SQL queries from a MySQL database.

---

## Packages
- requests
- json
- time
- datetime, timedelta
- mysql connector
- pandas

## Features

- View all asteroid approach data in an interactive table.
- Run predefined SQL queries (e.g., fastest asteroids, hazardous objects, closest approaches).
- Use filter criteria (date range, magnitude, velocity, diameter, etc.) to narrow down results.
- Execute custom SQL queries directly.
- Designed with an intuitive sidebar and clean layout.

---

## Tech Stack

- **Frontend/UI:** [Streamlit](https://streamlit.io/)
- **Backend:** Python + MySQL
- **Database:** Project_NASA_NEO
